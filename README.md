# AFTERFALL — Cinematic Apocalypse Stories

**AFTERFALL** — fictional cinematic survival transmissions from a world after the outbreak.

## Live project
Once GitHub Pages is enabled: https://kastew2005.github.io/afterfall/

## Episode 001 — THE FIRST SIGNAL
- Format: vertical 9:16 composition
- Runtime: 18 seconds
- Visuals: procedural Three.js city, abandoned cars, debris, infected silhouettes, survivor, rain, fog, emergency light and moving camera
- Language: Russian story captions with English archive branding

## Run
Open `index.html` in Safari or Chrome with an internet connection. Three.js is loaded from jsDelivr CDN. Tap **ПОВТОРИТЬ** to replay. On iPhone, if browser export is unavailable, use iOS Screen Recording from Control Center.
